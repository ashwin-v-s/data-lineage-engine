## How to reproduce

From the repository root:

```bash
# Full matrix (all levels x all seeds):
python scripts/run_benchmark_matrix.py

# Single cell, using the underlying runner directly:
python research/experiments/run.py --protocol research/protocol/v1.yaml --plumbing --loss-level 0 --seed 1
```

Each invocation writes `research/results/result_plumbing_mcar{level}_seed{seed}.json`; the matrix script consolidates all of them into `research/results/summary.json` and `research/results/summary.md`.
