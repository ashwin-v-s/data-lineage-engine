## What is done

### Core ingestion pipeline

| Item | File(s) | Description |
|---|---|---|
| `POST /api/v1/ingest/openlineage` | `backend/app/api/routes/ingest.py` | Accepts single event or batch of up to 100. Stores raw event idempotently by SHA-256 hash. COMPLETE events only produce `RUNTIME_POSITIVE` evidence rows. Missing events never create negative evidence. No cartesian-product edges. |
| `POST /api/v1/ingest/preview` | `backend/app/api/routes/ingest.py` | Validates and normalizes a file import without writing any rows. Returns asset/relationship counts, warnings, provenance. |
| `POST /api/v1/ingest/commit` | `backend/app/api/routes/ingest.py` | Idempotent write: one `import_run` + workspace-scoped `dataset`, `column_record`, `lineage_edge`, `evidence`, `edge_temporal_version` rows. Replays silently on duplicate key. |
| `GET /api/v1/ingest/runs` + `/runs/{id}` | `backend/app/api/routes/ingest.py` | List and retrieve import run history. |

### Source connector lifecycle (Architecture v2 §5.4)

| Item | File(s) | Description |
|---|---|---|
| `POST /sources` | `backend/app/api/routes/sources.py` | Register encrypted, workspace-scoped PostgreSQL connection. State → `CONFIGURED`. Credentials stored as AES-256-GCM ciphertext only. |
| `POST /sources/{id}/test` | `backend/app/api/routes/sources.py` | **Credential + reachability only** — connects, checks `is_superuser`, checks for write grants. Never performs schema discovery. Rejects superuser and write-granted credentials with `CREDENTIAL_TOO_PRIVILEGED`. State → `AUTHENTICATED` or `ERROR`. |
| `POST /sources/{id}/discover` | `backend/app/api/routes/sources.py` | Full schema read (separate step from `/test`). Returns asset/column counts for review. State → `DISCOVERY_COMPLETE` or `ERROR`. |
| `PATCH /sources/{id}` | `backend/app/api/routes/sources.py` | Update sync schedule (cron expression) or schema scope. |
| `POST /sources/{id}/sync` | `backend/app/api/routes/sources.py` | Persist discovered assets to catalog. Records `sync_job` row. State → `VERIFIED` or `SYNC_FAILED`. |
| `GET /sources/{id}/runs` | `backend/app/api/routes/sources.py` | Sync history from `sync_job` table with pagination. |
| `GET /sources/health` | `backend/app/api/routes/sources.py` | 12-field workspace rollup: connection_status, last_checked_at, last_successful_sync_at, last_sync_duration_ms, assets discovered/created/updated/unchanged, permission_gaps, sync_schedule, next_sync_at. |
| `DELETE /sources/{id}` | `backend/app/api/routes/sources.py` | Soft-revoke → `REVOKED`. Keeps all imported evidence as history (§9.9). |
| `kairos_reader` enforcement | `backend/app/api/routes/sources.py` | `_check_credential_privilege()` rejects superuser and write-granted credentials. Surfaces partial-SELECT permission gaps without blocking. |
| Migration 0010 | `backend/migrations/0010_m2_source_connection_lifecycle.sql` | Widens `lifecycle_state` CHECK from 4 to 16 states. Adds `next_sync_at`, `sync_schedule`, `sync_cursor`, `source_snapshot_hash`, `permission_gaps`, `last_successful_sync_at`, `last_sync_duration_ms`, per-sync asset counts. Creates `sync_job` table with RLS. |
