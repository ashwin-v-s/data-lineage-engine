# Three.js graphics skill pack

These skills were installed from
[scottstts/Threejs-Awesome-Graphics-Agent-Skills](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)
(MIT, Copyright © 2026 Scott Sun). They sit alongside the existing API-oriented
`threejs-*` skills and cover the visual craft rather than the API surface.

Installed:

- `threejs-skill-router` — route a visual target to the smallest expert set
- `threejs-camera-direction` — lenses, rigs, framing, pointer look
- `threejs-shadow-systems` — stable directional shadows, cascades, texel snapping
- `threejs-exposure-color-grading` — exposure, tone mapping, LUT order
- `threejs-screen-space-ambient-occlusion` — GTAO-style AO and reconstruction
- `threejs-image-pipeline` — shared depth/normal ownership across passes
- `threejs-bloom` — HDR extraction and selective glow
- `threejs-visual-validation` — deterministic evidence for visual work

The pack's own README and MIT licence live in the upstream repository; keep that
notice with the skills when redistributing them.
